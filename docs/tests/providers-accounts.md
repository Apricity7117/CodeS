# 模型与账号

当前产品只使用 Codex app-server 和 Codex 配置里的模型发现能力。第三方 provider、免费模式、自定义 endpoint 和代理 provider 不属于当前范围。

## Codex 账号面板

### 步骤

1. 启动 CodeS。
2. 打开侧边栏账号区域。
3. 如果未登录，运行 `codex login` 后点击 Reload。
4. 如果已登录，切换账号展开/折叠状态。

### 期望

- 账号列表来自 Codex app-server。
- 未登录时显示清晰的登录提示。
- Reload 不影响当前线程选择。

## 模型列表

### 步骤

1. 打开新线程或已有线程。
2. 展开模型选择器。
3. 修改 `~/.codex/config.toml` 中可用模型配置后刷新。
4. 再次展开模型选择器。

### 期望

- 模型列表来自 Codex `model/list` 和本地 Codex config 能发现的 provider-backed model ids。
- 设置页不出现第三方 provider、免费模式或自定义 endpoint 控件。
- 无法获取扩展模型时仍保留基础 Codex 模型列表。

## Per-thread 模型选择

### 步骤

1. 在新线程选择一个模型并发送消息。
2. 切换到另一个线程选择不同模型。
3. 返回第一个线程。

### 期望

- 线程级模型选择互不串扰。
- 新线程默认选择不覆盖已有线程选择。

## 配额与不可用账号

### 步骤

1. 使用已登录账号打开账号区域。
2. 触发配额刷新。
3. 模拟账号 API 失败或离线。

### 期望

- 成功时显示周额度、剩余额度或 unlimited 状态。
- 失败时显示不可用状态，不阻塞聊天主流程。
